# Filip Haraj — osobný web

Prezentačný web Filipa Haraja (AI engineer a web developer, Košice).

Čisté HTML, CSS a JavaScript bez build kroku — stačí otvoriť `index.html` alebo nasadiť na ľubovoľný statický hosting (GitHub Pages, Vercel, Netlify).

## Štruktúra

- `index.html` — obsah stránky
- `styles.css` — dizajn
- `main.js` — animácie, notifikácie na mobile, detaily projektov, kontaktný formulár
- `assets/img/` — obrázky

## Kontaktný formulár

Formulár spracúvajú **Netlify Forms** (formulár `kontakt`). Každá odpoveď sa uloží v Netlify
(Project → Forms) a príde e-mailom na harajfilip.co@gmail.com. Free plán zahŕňa 100 odpovedí mesačne.
